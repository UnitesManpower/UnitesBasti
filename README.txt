# Unites Manpower Consultant — free website

This is a static, mobile-friendly website. It uses plain HTML, CSS and JavaScript; there are no paid themes, plugins, databases or build tools.

## Files
- `index.html` — complete website

## Publish free with GitHub Pages
1. Create/sign in to a free account at https://github.com/
2. Create a new **public** repository named `unites-manpower-website`.
3. Upload `index.html` to the repository's top level (root).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. After GitHub publishes it, the address will be similar to:
   `https://YOUR-USERNAME.github.io/unites-manpower-website/`

GitHub may take a few minutes to publish the first time. Hosting and the GitHub Pages address are free. A custom `.com` domain is optional and costs extra.

## Before publishing
- Confirm the phone numbers, email and address are still correct.
- Add your approved company logo if you want to replace the text-based U mark.
- Add only verified vacancy details and any legally required registration/licence information. This starter site intentionally does not claim a licence or guarantee jobs, visas or selection.
- The enquiry form opens WhatsApp; it does not save submissions in a database.
